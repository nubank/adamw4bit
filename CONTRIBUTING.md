# Contributing
Thank you for considering a contribution. This project is maintained by
[Nubank](https://nubank.com.br) and licensed under the Apache License 2.0.
A contribution that is accepted becomes part of the project under that license.
## Questions and bugs
Open a GitHub issue for a usage question or for a bug that does not affect
security. 
## Security reports
Report a vulnerability through the private process in
[SECURITY.md](SECURITY.md). A public issue or pull request is not a suitable
place for exploit details.
